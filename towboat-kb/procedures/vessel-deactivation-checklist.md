# Vessel deactivation (engineering)

Outlines the process for bringing vessels in/out of a standby status. Reference: Vessel Operations Manual 2.4.
Coming back out: [Vessel activation checklist](vessel-activation-checklist.md).

- [ ] Cover exhaust stacks
- [ ] Cover Main Engine Air Intakes
- [ ] Cover machinery space air intake/exhaust vents if not in use or during cold weather
- [ ] Ensure moorings are adequate and secure, work with Mate on board if found to be inadequate
- [ ] Secure all tools, toolboxes, rigging
- [ ] Fuel tanks to be sounded daily
- [ ] Daily Lay-Up Checklist in Ripple, Equipment hours log, and equipment readings to be completed daily
- [ ] Verify no excessive flow from shaft packing glands or seals
- [ ] Test bilge high level alarms
- [ ] Test fuel tank high level alarms if vessel equipped
- [ ] Shut down all unnecessary electronics, but NEVER machinery alarm system or Fire Alarm Panel
- [ ] Lock exterior doors when no personnel on duty
- [ ] Review repair plans, if applicable, with Port Captain and Port Engineer
- [ ] Make frequent security and fire-watch rounds through the vessel
- [ ] Check email at least once a day
- [ ] Refer to **_Conquer Checklist – External & Internal Transfer Procedures_** if a fuel transfer is to be conducted while deactivated. Gravitational transfers are prohibited when a vessel is going on or coming off dry-dock.

Gravitating between tanks, when it is allowed: [Gravitating fuel between tanks](gravitating-and-fuel-valves.md).
