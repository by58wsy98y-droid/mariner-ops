# Maintenance procedure cards

The company's step-by-step maintenance and technical procedure cards (MPCs), one file per card, named
after the MPC code. The fields at the top (MPC code, frequency, revision date, what it applies to) show as
the card's header; `equipment:` (engine, generator or gear) puts the card on every boat page that lists
that equipment. Pictures from a card go in `images/`.
